Personal Portfolio Website

A responsive personal portfolio website developed using React.js and Vite to showcase my technical skills, projects, education, and professional profile.

Live Demo

"View My Portfolio" (https://suhail-portfolio-sigma.vercel.app)

Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

Features

- Responsive and user-friendly interface
- Personal introduction and professional profile
- Technical skills showcase
- Projects showcase with project details
- Education details
- GitHub and LinkedIn profile links
- Live project demonstrations
- Easy navigation across sections

Development Tools

- Visual Studio Code
- Git
- GitHub
- Vercel

Installation and Setup

1. Clone the repository:
   
   "git clone https://github.com/suhail2203/Suhail-Portfolio.git"

2. Navigate to the project directory:
   
   "cd Suhail-Portfolio"

3. Install dependencies:
   
   "npm install"

4. Start the development server:
   
   "npm run dev"

5. Open the local URL displayed in your terminal.

Deployment

This portfolio website is deployed using Vercel.
